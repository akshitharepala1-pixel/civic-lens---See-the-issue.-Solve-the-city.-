# civic-lens---See-the-issue.-Solve-the-city.-

CIVIC LENS:
Civic lens is an AI-powered civic intelligence platform that helps citizens report civic issues, identify responsible departments and track community problems through a 
transparent and smart system.

FEATURES:
1. multilingual reporting: Report issues through text, images, audio or video.
2. AI issue analysis: automatically categorizes issues and estimates urgency.
3. Smart department routing: suggests the appropriate department.
4. Civic Duplicate Fusion: groups similar nearby reports.
5. Impact radar: visualizes civic issues through an interactive map.
6. Transparency Dashboard: tracks reports and their progress.

GOAL:
to make civic reporting smarter, simpler, accessible and more transparent by connecting citizen observations with actionable information
